**What "read" means / thresholds (OFFICIAL, "General conditions", verbatim)** — [scrollprize.org/prizes#2027-grand-prize](https://scrollprize.org/prizes#2027-grand-prize)
- "Pipeline fully reproducible and code shared under an open source license (e.g. MIT), published publicly on GitHub. It does not have to be open source at the time of submission, but you have to make it open source under a permissive license, publicly on GitHub, to accept the prize."
- "Pipeline should be seamlessly integrated in the VC3D software."
- "100% of the papyrus recto surface unrolled. **Submission package (verbatim excerpts)** — [scrollprize.org/prizes#2027-grand-prize](https://scrollprize.org/prizes#2027-grand-prize)
- Meshes: "a set of meshes in tifxyz format whose union corresponds to the totality of the scroll surface to be virtually unwrapped. Each tifxyz must already include a low-distortion isometric 2D parametrization (flattening). At most one mesh per full column of text (plus its margins) will be accepted ... Name each mesh with a sequential column number (e.g. `column_01.tifxyz`, `column_02.tifxyz`, ...) following the order of the windings".
- Images: "a single static image for each column or sequence of consecutive wraps. Images must be generated programmatically from the reconstructed CT scan volume and the corresponding mesh submitted in the same package, and should not contain manual annotations of characters or text"; named after the mesh; "scale bars showing the size of 1cm on each submission image"; plus "a single banner image spanning the full unrolled scroll, showing ink detection results across all columns, with each column's number overlaid on it".
- Methodology: "A detailed technical description of how your solution works ... Please create a Docker image that we can easily run to reproduce your work, and please include system requirements."
- False-positive mitigation: "Large windows are fine, but you must demonstrate that the text is not hallucinated — for example by finding plausible text on held-out regions."
- Held-out validation: "Run your method on the public input renders/volumes with known ground truth (using k-fold validation if you trained on them) and include the results. We may also run your method, following your instructions, on held-out data with known ground truth."
- Grand Prize form fields (read-only view): full name; team name ("required if on a team; the team leader should be the one filling out this form"); "Scroll / Volume made readable"; "Additional information as described on https://scrollprize.org/prizes" (link to GitHub repo, Google Doc, Drive, PDF); mandatory "Yes, I agree" to the Terms and Conditions. — [Grand Prize form](https://forms.gle/wvNK7DkNKuRKjHJdA)

### Inferences
- The search-level claim "$2,140,000 open pool" is confirmed as the banner figure but overstates money actually winnable before 2027-06-25: milestone prizes total $1,450,000 (1,000,000 + 400,000 + 50,000); the $590,000 is an annual Progress Prize budget figure, not a guaranteed payout (the only guaranteed amount is $20,000/month). Using the body's $400,000 the consistent sum is $2,040,000.
- "A second complete scroll" is correct in spirit: the first complete read (PHerc. 1667) was done by the in-house team in 2026; the Grand Prize requires any one of the 13 listed volumes.
- For a solo participant the Grand Prize is extremely demanding: 100% recto unrolled (max 10% disconnected outer patches skipped), ≥70% legible characters in every counted column, VC3D integration, Docker reproduction, public datasets/checkpoints/W&B runs, ≤8 documented human hours on the unrolling itself. The 8-hour cap applies to the unrolling pipeline for the submitted scroll; generic training-dataset creation is explicitly unlimited.
- The papyrologist and technical reviewers are not named on the current page; the named 2023 Review Team (Seales, Friedman, Parsons, Parker, Posma, Havíř; Fowler, Reinhardt, Janko, Nicolardi, Del Mastro, Delattre) is on an ARCHIVED page and is historical. — [archived /grand_prize](https://scrollprize.org/grand_prize)

- Exact definition of "counted column" and how "preserved characters" are enumerated is not specified beyond the quoted text.
- No current named list of judges for 2027.
- Whether the $590,000/year Progress budget is a hard commitment: not confirmed (only stated as frontmatter `amount: 590000, unit: "per year"`).

## 4. Eligibility: country restrictions, sanctions, age, teams, tax/payment, open-source licence, IP

### Takeaway
The only stated geographic restriction is US sanctions ("As long as we can legally pay you (no US sanctions) you can win prizes"); there is no stated age rule or country list. ### Inferences
- Calibration: the $20,000 award has gone four months running to substantial unwrapping/segmentation methods (auto mesher, patch-based unwrapping with measured cm² coverage, fiber extraction integrated into VC3D/spiral fitter, new surface networks). Ink models that the community actually adopts earned $5,000. A solid new method/prototype earns ~$1,000; a tool, experiment report or bundle of merged PRs earns $250–$500.
- The number of awards grew from 2 (May) to 33 (October), so the low tiers are increasingly accessible: a handful of merged, in-use bug/compatibility fixes to ScrollPrize/villa (including Apple Silicon/MPS fixes) reliably earned $250–$500 in Sept–Oct 2026.
- Several people moved from small awards to large ones over consecutive months (e.g. Erwin Nieuwlaar: $1,000 July, $500 August, then a $50,000 First Letters in October; Samir Lerognon: $20,000 September, $2,500 October), which suggests sustained, visible work is rewarded.
- Audit/evaluation-only tools were rewarded in July (windcheck, TIFXYZ Doctor, scroll-data-audit at $1,000) but the page now says such standalone tools are discouraged (when that sentence was added was not checked; a commit titled "tweaks to prize & problems wording" landed 2026-11-05), so that route looks weaker now.
